# Keizai

Androidで動く、ファンタジー世界の文明を**観察する**ゲーム。

プレイヤーは神として、鉱石・木材・収穫・魔物という4つのダイヤルと、干魃や疫病といった災厄を操るだけ。誰が王になるか、どの組織が興り、いつ袂を分かつかには一切触れられない。それでも人類の側は、環境の変化に応じて権力の均衡を組み替え、必要に迫られて**新しい仕組みを自ら発明していく**。その様子を年代記と系譜図で追いかけるのがこのゲームです。

世界に最初から在るのは、**地域の数だけの貴族家**と**その下に付く側近家3つずつ**、ギルド・派閥・政体が1つずつ、そして**司祭も教義もないアニミズム**。討伐ギルドも、商業ギルドも、魔術師ギルドも、神殿派閥も、組織された宗教も、**世界がそれを必要としたときに、既存のものから分派して生まれます**。だからどれだけ枝分かれしても、すべては必ず最初の1つまで遡れます。

そして**人は無から湧きません**。建国時の家々に生まれた者と、その子孫だけがこの世界の登場人物です。ギルド長も国王も、必ず誰かの子です。家が子を残せなければその家は絶え、絶えた家は二度と戻りません。婚姻だけが家と家を繋ぎ、血を混ぜ、そして次の世代を生みます。

苗字は家の名前そのものです。分家すれば苗字も変わり、家名を改名すれば一族全員の名前が変わります。

## 画面

| 画面 | 内容 |
|---|---|
| 世界 | 地域の地図。産業・主なギルド・領主(家格つきの称号)・この地が支持する派閥・**信仰**・人口・不満を確認でき、地名も改名できる |
| 年代記 | 起きたことの記録。分派／継承／人物／災厄／側近家で絞り込める。側近家の出産・婚姻・死没は他を埋め尽くすので別枠 |
| 系譜 | **組織／家／人物**の3画面。組織はギルド・派閥・政体・信仰の分派図。家は貴族家の分家図（選ぶと**なぜ分かれたか**が当時の文章つきで出る。「この家の家系図」から**その家だけの家系図**へ）。人物は既定で**当主のみ**を一本の筋として描き、**長押しでその人の系図**が開く |
| 関係 | 勢力図。貴族家をその所領の上に置き、仕える側近家がその周りを取り巻く。家同士の線は友好（緑）と反目（赤）、側近家からの線は忠誠の色。**家をタップするとその家の縁だけが明るくなり**、残りは背景に退く |
| 勢力 | 統治のかたち・議席の配分・体制に迫る者。開くと「なぜ強いのか」の内訳、支持基盤、**歴代の長**、側近家とその忠誠が出る |
| 神の力 | 4つのダイヤルと7つの災厄・恵み。プレイヤーにできるのはこれだけ |

### 家系図の3つの読み方

同じ記録を3通りに描き分けます。

- **全体の家系図** — 世代ごとに並べた一枚の図。全員がちょうど一度だけ現れ、家と家をつないでいるのは婚姻の線。既定では当主のみの筋に絞られます
- **その家だけの家系図** — 家の系譜から「この家の家系図」で開く。その姓を名乗る人と、**嫁いできた配偶者**が載り、**他家へ出た人は載りません**（その人は嫁ぎ先の家系図にいます）
- **個人の系図** — 全体図で誰かを**長押し**すると開く。源流までの直系と、その各代の**きょうだいまで**を描きます。祖父母の子（叔父叔母）は載りますが、その子（従兄弟）は載りません。一歩外まで、それ以上は追わない

### 横のつながり

4つの要素は横に繋がっています。すべて、実際に起きたことから毎エポック読み直されます。

- **家 → ギルド／派閥**：同じ家から長官が出続けたギルドは、その家のものになります（**世襲制**）。そうなると次の後継もその家から選ばれ、ギルドの思想自体が世襲を認める方向へ動く。家が絶えれば所有も解け、座は再び**実力制**や**協議制**で争われます。
- **家・ギルド → 派閥**：派閥には**支持基盤**があります。理念が近い家、同じ家に握られたギルド、その派閥が代弁する産業の土地を持つ家。誰が支えているかは勢力画面で確認できます。
- **派閥 → 政体**：政体には議席があり、派閥の力と各地域の支持で配分されます。議席数は政体の形で決まります（専制の宮廷は7、民会は25）。
- **土地 → すべて**：地域の産業が、そこで力を持つギルドと、そこが支持する派閥を決めます。その地を治める家は、両方を都に持ち込みます。

### 家格

貴族家は**男爵・子爵・伯爵・侯爵・公爵**の位を持ちます。側近家には**従士・下級騎士・騎士・準男爵**という別の梯子があり、そのてっぺんの準男爵でも最下位の男爵より下です。普段はほぼ全員が従士で、上の段は生まれではなく**主家の家督争いで旗色を当てた**ことで得られます。所領・influence・王冠・家の古さから毎回導かれ、公爵は国に一人だけという定員があります。

重要なのは**どれだけ重視されるかが場合による**ことです。世襲王権では家格がものを言い、民衆共和国ではほとんど意味を持ちません。商人ギルドや神殿は出自のよい役員を欲しがり、狩人や職人のギルドは気にしません。同じ家名が、ある世紀には決定的で、次の世紀には何の意味も持たなくなります。

### 統治のかたちと政変

「派閥」と「政体」が何を表すのかは、**両者の力関係から決まる政体の形**として表に出ます。神殿派閥が最も強ければ神権国家に、商業ギルドが強く議会があれば商人共和国に、家々が領を分け持てば封建王国に。

そして**国の仕組みそのものが奪われます**。議席の過半を握った派閥、王冠より重くなったギルド、抑えの利かなくなった民衆——誰かが国を支えている状態が続くと政体の正統性は削れていき、限界を越えると**政変**が起きます。何を正統性の根拠とするか（世襲／選挙／実力／神権／軍事／金権）と、誰が決めるか（専制／評議制／議会制）が書き換えられ、血筋に依らない体制になれば王は座を追われます。

### 危機が生む新しい politics

不満が限界を越えれば**平等派**が、災厄が続けば**終末教団**が、魔物の脅威が存亡に関わるところまで来れば**軍政派**が、富が王の徴税を越えれば**自由都市派**が、資材と魔術が伝統を追い越せば**秘儀技術派**が生まれます。これらは親派閥の思想を少しずらしたものではなく、**正統性の根拠と意思決定の形ごと否定した別物**です。同じ類型の組織は3つまでしか並び立たないので、似た派閥ばかりが並ぶことはありません。

### 身分 ── 貴族と側近家

各貴族家には**側近家**が3つ付いています。平民ではなく、貴族でもない。領地を持たず、貴族との婚姻は容易ではない。だからこそ**行き先がある**のがこの身分の要点で、道は3つあります。

| 道 | 条件 |
|---|---|
| **反乱** | 忠誠を失い、なお主家に匹敵する力を持ったとき、実力で領を奪う |
| **血統的乗っ取り** | 主家の生きている血の過半が側近家由来になり、誰も忠義を惜しまなくなったとき、争いなく家督が移る |
| **恩賞** | 政体を奪った貴族が、敵対する貴族から領を没収して降格させ、自分の腹心を貴族に列する |

逆向きも起きます。降格した貴族家は消えるのではなく、**自分を負かした家の側近家に落ちる**。その孫の代がまだ払っている借りです。

身分を越えた婚姻は「重み付け」ではなく**拒否**されます。ただし、同格の家すべてと不仲になった家には他に相手がおらず、そのときだけ線が越えられる。越えた縁組は多くの場合**駆け落ち**として扱われ、当人たちは家から除かれて一段下の家として再出発します。

### 宗教

世界は**アニミズム**から始まります。司祭も教義も指導者もなく、山と川と死者に祈るだけ。これが信仰系統の根であり、後のすべての宗教はここまで遡れます。

組織された宗教は、世界が求めたときに分派します。凶作が続けば豊穣信仰、魔物が夜ごと出れば守護神信仰、家々の重みが増せば祖霊信仰、資材と魔術が溢れれば秘儀信仰、災厄が重なれば終末信仰。生まれた信仰は最初の一地域を得て、そこから広がります。地域が改宗し、その地の家が信仰を改め、家が自分の他の所領にそれを持ち込む——という循環です。

### 家風

家には**貴族一家・神官一家・騎士一家・学究一家・商家・郷士の家**という性格があります。建国時は土地の産業から決まり、以後は**その家が実際に何をしてきたか**で読み直されます。代々神殿に子を出していれば、何から始まったかに関わらず神官一家です。

家風は効きます。**学究一家**が長を出している組織は分派しやすく、**貴族一家**は封建王国の形そのものを支えていて、諸家が貴族一家でない王国は同じ王冠でも脆い。

### 継承と家督争い

**継承は基本的に揉めません。** 世襲の座は長子が継ぎ（男子優先）、誰も何も言いません。争いが起きるのは理由があるときだけ——跡取りが明らかに兄弟姉妹より劣る、野心的な者が隙を見る、家長が幼い直子を残して没して家督が横に流れる。座を選挙や実力で埋める組織（ギルドや派閥）は、そもそも「争い」ではなく**選出**として記録されます。

争いになった場合は、**穏やか／中程度／激しい**の三段階で決着します。段階は、票差の僅少さ・敗者の野心・座の重み・**幼君**（家長が幼い直子を残して没し、家督が横に流れる）から決まります。

| 段階 | 決着 |
|---|---|
| 穏やか | 敗者は争わずに**隠居**する。その座には二度と担がれないが、他の役職には就ける |
| 中程度 | 敗者は家を出て**分家**を立てる（世界に家を増やす余地がない場合は隠居に落ちる。起きなかった出奔を年代記に書かないため） |
| 激しい | 敗者は**廃嫡**され、家を追われる。以後どこの座にも就けない |

中程度以上では**側近家が旗色を選びます**。誰を推したかは年代記に名指しで残り、勝者を推した家は格が上がり、敗者を推した家は下げられます。

### 分家の理由

家が割れるには他にも理由があり、年代記にその理由が残ります。**跡目不当**（家長の器量が足りず、明らかに優れた兄弟姉妹が仕えることを拒む）、**駆け落ち**（家格を越えた縁組を家が認めない）。

### 家同士の関係

家と家の関係は、実際に起きたことから毎回読み直されます。婚姻で結ばれていれば近づき、同じギルドの座を争っていれば離れ、理念が隔たれば冷えていく。王冠を戴く家は、戴かない家から妬まれます。関係は蓄積された感情ではなく現状の反映なので、原因が消えれば対立も終わります。

## 設計

詳細は [`docs/DESIGN.md`](docs/DESIGN.md)。要点だけ:

- **系譜の追跡可能性** — 組織の設立・分派・継承はすべて `HistoryLog.record()` を通り、そこから `GameState.apply()` が状態を書き換える。他の経路から書き換えることはできないので、年代記と系譜が食い違うことがない。系譜に不可欠な出来事は圧縮されない永続領域に残る。
- **権力の算出はデータ駆動** — 「魔物が多いと討伐ギルドが強くなる」は特別扱いではなく、`data/power_profiles/*.tres` が宣言した世界変数の重み付けの一例。新しい組織の類型を足すのに、エンジン側のコード変更は要らない。
- **政治体制は生成される** — 固定パターンから選ぶのではなく、権力基盤×意思決定構造の離散2軸と、世界の状況に応じて漂流する連続5軸から組み立て、そこから体制名と説明文を生成する。ギルドや派閥の思想も同じ仕組み。
- **神の権限の境界** — `GodPowerAPI` には組織も人物も権力値も渡せない。この境界はテストで機械的に検証している。

## 開発

Godot **4.7** 以上（`Dictionary[K,V]` の型付き構文を使うため 4.4 が下限）。

```bash
# エディタで開く
godot --path .

# ヘッドレスのテスト（約10分、6万件超の検証）
godot --headless --path . res://tests/TestRunner.tscn

# 数百年ぶんを一気に回して結果を眺める開発用ツール
godot --headless --path . res://tools/Diagnose.tscn -- --ticks=2400 --seed=7

# 各画面のスクリーンショット（要 xvfb）
xvfb-run -a --server-args="-screen 0 720x1280x24" \
  godot --path . res://tools/Screenshot.tscn -- --out=/tmp/shots
```

テストには系譜の不変条件が含まれます。2万ティック回した世界に対して、すべての組織が種別ごとにただ1つの根へ到達すること、循環がないこと、すべての人物の家系が始祖で終わること、セーブが完全に往復すること、同じシードが同じ歴史を生むことを検証しています。

## Android APK のビルド

必要なもの:

- Godot 4.7 本体と、**同じバージョンの** Android エクスポートテンプレート（エディタの *Editor → Manage Export Templates* から導入）
- JDK 17 以上
- Android SDK の build-tools（`apksigner`, `zipalign`, `aapt2`）と platform-tools（`adb`）
- Godot のエディタ設定で `export/android/android_sdk_path` と `java_sdk_path` を上記に向ける

```bash
# デバッグ版（Godot が自動生成するデバッグ鍵で署名される）
godot --headless --path . --export-debug "Android" build/keizai-debug.apk

# リリース版 — 鍵はリポジトリに置かず環境変数で渡す
export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/secure/path/keizai-release.keystore
export GODOT_ANDROID_KEYSTORE_RELEASE_USER=keizai
export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=...
godot --headless --path . --export-release "Android" build/keizai-release.apk
```

リリース鍵は `keytool -genkeypair -v -keystore keizai-release.keystore -alias keizai -keyalg RSA -keysize 2048 -validity 10000` で作成し、**リポジトリの外に置いて必ずバックアップ**してください。これを失うと同じ Play Store の掲載を更新できなくなります。

ビルド結果の実測値:

- 最小 SDK 24（Android 7.0）／ターゲット SDK 36（Android 16）
- arm64-v8a のみ（32bit を含めると 59MB になるため既定では外しています。必要なら `export_presets.cfg` の `architectures/armeabi-v7a` を `true` に）
- 権限要求は**ゼロ**（通信・位置情報・カメラのいずれも使いません）
- デバッグ 32MB／リリース 30MB

**ターゲット SDK は提出時に Google Play の当時の要件を確認してください。** この要件は毎年上がります。

### 未検証の項目

このリポジトリの APK はコンテナ内でビルド・署名検証まで確認済みですが、**実機での起動確認は行っていません**（実行環境に Android 端末もエミュレータもないため）。実機で確かめるべきは、タップ操作の感触、ピンチ操作、長時間放置後の復帰、セーブの読み込み時間です。
