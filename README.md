# Keizai

Android向けファンタジー文明観察ゲーム(仮)。プレイヤーは「神」として鉱石・木・収穫/凶作・魔物などの環境リソースや災害を操作するだけで、ギルド・政治体制・王家・派閥が独自に発展し、分裂し、新しい仕組みを生み出していく様子を観察する。
