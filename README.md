# Keizai

Androidで動く、ファンタジー世界の文明を**観察する**ゲーム。

プレイヤーは神として、鉱石・木材・収穫・魔物という4つのダイヤルと、干魃や疫病といった災厄を操るだけ。誰が王になるか、どの組織が興り、いつ袂を分かつかには一切触れられない。それでも人類の側は、環境の変化に応じて権力の均衡を組み替え、必要に迫られて**新しい仕組みを自ら発明していく**。その様子を年代記と系譜図で追いかけるのがこのゲームです。

ただ眺めるだけではありません。神は**未来を告げる**ことができます。「この家が王座に就く」「このギルドが天下を取る」——告げた未来へ、ダイヤルと災厄だけで世を導き、当たれば**神威**が満ちて、さらに大きな災厄を下せるようになります。

世界に最初から在るのは、**地域の数だけの貴族家**と**その下に付く側近家3つずつ**、ギルド・派閥・政体が1つずつ、そして**司祭も教義もないアニミズム**。討伐ギルドも、商業ギルドも、魔術師ギルドも、神殿派閥も、組織された宗教も、**世界がそれを必要としたときに、既存のものから分派して生まれます**。だからどれだけ枝分かれしても、すべては必ず最初の1つまで遡れます。

そして**人は無から湧きません**。建国時の家々に生まれた者と、その子孫だけがこの世界の登場人物です。ギルド長も国王も、必ず誰かの子です。家が子を残せなければその家は絶え、絶えた家は二度と戻りません。婚姻だけが家と家を繋ぎ、血を混ぜ、そして次の世代を生みます。

苗字は家の名前そのものです。分家すれば苗字も変わり、家名を改名すれば一族全員の名前が変わります。そして家には**氏（うじ）**があり、どの家がどこから分かれたのかが名前に書かれます（「ネシ氏コド家」「ネシ氏コド・ハル」）。

国はふつう、体制が倒れれば丸ごと替わります。けれど旧体制を支える地方が多いとき、あるいは暗殺や王都制圧のような力ずくの交代のときは、**国が割れて内戦になります**。戦の決着と戦後処理で、家・ギルド・派閥・信仰が大きく動きます。そしてごく稀に、後の世が**偉人**として名を残す者が現れます。

国には長のほかに摂政・財務官・跡目家といった**要職**があり、家格は「摂政を三代出した」「跡目家の第一位」のような**数え上げられる根拠**の合計です。要職をめぐっては宮廷で**政争**が起き、家督争いの**遺恨**が何代も後に意趣返しとなって返ってきます。そして、ある程度自由な国では**思想**が生まれ、思想家の手で改められ、分かれ、国是となり、廃れ、また蘇ります。

## 画面

画面の上部には年・統治のかたち・人口（交戦中は「交戦中 n年目」、国が分かれていれば「2国分立」）、**神威と告げている神託の数**（タップで神の力へ）、「？」、停止／1倍／2倍／4倍と、魔物・不満・収穫・鉱石・木材のゲージ（**前回からの増減の矢印**つき）。下のドックのすぐ上に**ニュース欄**があり、最新の見出しが一行で出ます（タップでその出来事へ）。

### 神託・神威・史録

神にできるのは今も世界を変えることだけですが、**変える理由**があります。

- **神託** — 「30年のうちにこのギルドが世で最も力ある組織となる」「40年のうちに王都制圧が起きる」「50年のうちにこの家の血が絶える」。いまの世界から読み取った未来を3つの中から選んで告げ、あとは四つの理と災厄だけでそちらへ導きます。覇権・王座・断絶・啓示・分裂・破局・政変・興亡・繁栄・衰亡・長寿・叙爵・摂政・跡目・政争・国是・思想の衰退の17種。各神託には**いまの状況**（何位か、機運何％か、存命何人か）と**どの理が効くか**が付きます。同時に3つまで
- **神威** — 年に1ずつ満ち、神託が成就すると大きく満ちる（最大150）。災厄と恵みはこれを費やす（祝福の森15〜疫病45）。設定で制約をなくせます
- **史録** — 王朝交代、四つの破局、百寿、五百年の家、無為の神、内戦・復古・再統一、偉人、家職・摂関政治・跡目の継承、最初の政争・三代越しの意趣返し、最初の思想・国是・思想の復興……43の偉業。最後に**諸世界の偉人**の名簿も付きます。どの世界で見届けたものも残り、タイトル画面からも見られます
- **時代** — 年代記は50年ごとの章に区切られ、「疫病の時代」「大乱の時代」「凪の時代」のような名前と、その半世紀の要約が付きます。章が閉じるとニュースで知らせます

神託の対象になった家は地図で光り、勢力の一覧にも印が付きます。神託もその結果も、セーブに残ります。

### 氏（うじ）

氏を興せるのは、**ゲーム開始時に地域を治めていた主家だけ**です。その家名がそのまま氏の名になります（ネシ家 → ネシ氏）。

- 開始時の側近家は**主人の氏**を名乗ります（ネシ氏カベ家）
- それ以降に生まれる家は、分家でも駆け落ちでも認知でも、**分かれ元の家の氏**を受け継ぎます
- 氏は一度決まったら**変わりません**。主替え・昇格降格・改易・断絶・改名でも変わらず、家が絶えても氏は残った家に続きます
- 名乗りは、**氏を興した家（宗家）の者だけ**が「ネシ・名前」。それ以外の家の者は必ず「ネシ氏コド・名前」。家は「ネシ家」と「ネシ氏コド家」
- 宗家を改名すると氏の名も変わり、その氏のすべての家の書き方が変わります。それ以外の家の改名は、自分の家名の部分だけが変わります
- 年代記にすでに書かれた文章は書き換えません（その時の名前のまま残ります）

**紋章** — 家にはそれぞれ盾の紋章があります。色は家ごと、図柄（縦帯・山形・十字…）は**氏ごとに一つ**で、同じ図柄の家は同じ氏——元をたどれば一つの建国の家です。地図・勢力・関係・系譜のどこでも同じ紋章で出ます。

**ニュース** — どの画面を見ていても、分家・新しい信仰・家督争い・災厄・神託の進み具合などはドックの上のニュース欄に見出しとして出ます（タップでその出来事へ。画面の操作を覆いません）。50年の章が閉じるときは、その時代の名前が画面を横切ります。事件・政変・国の興亡のような大事件は画面全体で知らせ、**読み終えるまで時を止めます**（設定で切れます）。

### 家系図の3つの読み方

同じ記録を3通りに描き分けます。

- **全体の家系図** — 世代ごとに並べた一枚の図。全員がちょうど一度だけ現れ、家と家をつないでいるのは婚姻の線。既定では当主のみの筋に絞られます
- **その家だけの家系図** — 家の系譜から「この家の家系図」で開く。その姓を名乗る人と、**嫁いできた配偶者**が載り、**他家へ出た人は載りません**（その人は嫁ぎ先の家系図にいます）
- **個人の系図** — 全体図で誰かを**長押し**すると開く。源流までの直系と、その各代の**きょうだいまで**を描きます。祖父母の子（叔父叔母）は載りますが、その子（従兄弟）は載りません。一歩外まで、それ以上は追わない

### 横のつながり

4つの要素は横に繋がっています。すべて、実際に起きたことから毎エポック読み直されます。

- **家 → ギルド／派閥**：同じ家から長官が出続けたギルドは、その家のものになります（**世襲制**）。そうなると次の後継もその家から選ばれ、ギルドの思想自体が世襲を認める方向へ動く。家が絶えれば所有も解け、座は再び**実力制**や**協議制**で争われます。
- **家・ギルド → 派閥**：派閥には**支持基盤**があります。理念が近い家、同じ家に握られたギルド、その派閥が代弁する産業の土地を持つ家。誰が支えているかは勢力画面で確認できます。
- **派閥 → 政体**：政体には議席があり、派閥の力と各地域の支持で配分されます。議席数は政体の形で決まります（専制の宮廷は7、民会は25）。
- **土地 → すべて**：地域の産業が、そこで力を持つギルドと、そこが支持する派閥を決めます。その地を治める家は、両方を都に持ち込みます。

### 家格

貴族家は**男爵・子爵・伯爵・侯爵・公爵**の位を持ちます。側近家には**従士・下級騎士・騎士・準男爵**という別の梯子があり、そのてっぺんの準男爵でも最下位の男爵より下です。普段はほぼ全員が従士で、上の段は生まれではなく**主家の家督争いで旗色を当てた**ことで得られます。爵位は**家格の根拠の合計**（下の「要職と家格の根拠」）から毎回導かれ、公爵は国に一人だけという定員があります。

重要なのは**どれだけ重視されるかが場合による**ことです。世襲王権では家格がものを言い、民衆共和国ではほとんど意味を持ちません。商人ギルドや神殿は出自のよい役員を欲しがり、狩人や職人のギルドは気にしません。同じ家名が、ある世紀には決定的で、次の世紀には何の意味も持たなくなります。

### 爵位は与えられるもの

家格は「持っているもの」から導かれますが、**授けるもの**でもあります。

- **王家は爵位を持ちません**。王国である限り、王冠を戴く家は公侯伯子男のどれでもなく「王家」であり、爵位の序列そのものの外に立ちます。爵位とは王家が与えるものだからです。かわりに公爵の席が一つ空き、他の家がそこに入ります。王冠を失えば、その家は普通の貴族として序列に戻ります。
- **王家は叙勲と降格ができます**。近しい家の家格を引き上げ、敵対する家の家格を削る。これが王権が貴族に対して日常的に持つ唯一の力です。引き上げられた家は王家に恩を感じ、削られた家は一代覚えています。ただし爵位は依然として実力から導かれるので、恩賞は序列を動かすだけで固定はしません。何も持たない家をいくら引き上げても、いずれ下がります。
- **側近家の位は主家が自由に授けられます**。誰も止められません。ただし**その価値を決めるのは世界全体**です。皆が騎士になれば騎士であることの敷居が上がり、位は元の希少さに戻ります。乱発した家は、同じ通貨を持つ他家から疎まれます。そして家中の全員が同じ位なら、誰も特別ではなくなり、恩賞で買ったはずの忠誠が静かに抜けていきます。

### 没落したあと

追放・廃嫡・反乱・革命の当事者がその後どうなったかも、世界が計算して書き残します。

- **廃嫡された人**は、家格を惜しまれて**新しい分家として認められる**か、受け入れる家に**嫁ぐ／婿に入る**か、縁のある家に**引き取られる**か、どこからも声がかからず**市井に下る**。どれになるかは、その人の重み・他家との関係・血縁から決まります
- **王座を追われた者**は、家が残っていればそこへ退きます。家ごと失っていれば上と同じ道を辿ります
- **主家が絶えた側近家**は、まず空いた領を継げるなら継いで貴族になり、継げなければ**別の主家へ移り**（縁組や領の縁を優先）、仕えるべき家がどこにも無ければ**士分を退いて民に戻ります**

系譜画面では、その人の「その後」と「追われた座」「廃嫡」が本人の欄に残ります。

### 信仰は世界の割れ具合で重みが変わる

信仰は、世界がどれだけ割れているかに比例して他の全部に効きます。**一つの信仰しかない世界には宗教政治が存在しません** — 全員が同意しているとき、同意には何の価値もないからです。割れた世界では、他に何も無いくらいの重みを持ちます。

- **家同士** — 同じ信仰の家は近づき、違う信仰の家は離れる
- **支持基盤** — 家は自分と同じように祈る組織を支える。信仰そのものも派閥の支持者になる（啓示が典礼で終わらず政策になる経路）
- **土地** — 別の信仰の家に治められている地方は言うことを聞くのが遅い。それが不満になり、不満は体制への挑戦になる
- **国** — 世の3分の2を占め、説く座を持つ信仰は、**国そのものを要求できます**（神権国家への政変）

### 事件

普段この世界は少しずつしか動きません。それは大抵の物事には正しい速度で、**歴史が記憶される瞬間には間違った速度**です。事件はもう一方の種類の出来事 — 独立した圧力が2つ3つ同時に揃うことを要求し、一季節で起こり、その後に続くのは、それまで続くはずだったものではありません。

| 事件 | 条件 |
|---|---|
| **破門** | 世の3分の2を占め説く座を持つ信仰／自前の土地を持つ対抗宗派の大家／その家より強い信仰 |
| **暗殺** | 口も利かないほど険悪な二家／不満の高まり／殺す価値のある役職 |
| **王都制圧** | 国より明らかに強い武の組織／民が門を開くほどの不満／威信を失った国 |
| **民衆蜂起** | 国の半分以上の地方が沸騰／選挙制でない国 |

結果は普通の記録を通ります（死、権力の移動、体制の崩壊）。事件タブでは**何が起きたか**だけでなく、**いま何がどこまで高まっていて、何が足りないか**が読めます。穏やかな世界では一つも起きません — 見たければ、神が条件を作りに行く必要があります。

### 国が割れるとき ── 内戦

体制が倒れるその瞬間に、地方ごとに「旧体制に付くか、新体制に付くか」が決まります。材料は、その地を治める家と倒される長の家との関係（同じ氏か、友好か反目か）、挑戦者の支持基盤、その地が支持する派閥、信仰、不満、旧体制の正統性。暗殺や王都制圧・蜂起のような**力ずくの交代**は、反発を生んで旧体制側に寄ります。旧体制側が人口で**およそ3割（力ずくなら2割）以上**、かつ双方が2地方以上あるときだけ国が割れ、そうでなければ今まで通り丸ごと替わります。

- **分裂** — 新体制は旧体制の枝として興り（政体の系譜は一つの根のまま）、旧体制は自分に付いた地方で続きます。王都を失った側は都を移します
- **戦** — 年に一度、両陣営の力がぶつかります。力は治める地方の人口と富、飢え、味方の家（家格・騎士一家なら上乗せ）、味方のギルドと派閥（討伐・軍政は武、職人は武具、商人は軍資金）、正統性、足元の不満、旧体制の備え。ダイヤルと災厄は世界全体に効きますが、**陣営が何でできているかによって効き方が違います**（討伐ギルドを抱える側は魔物に強く、飢えた地方の多い側は凶作に弱い）。ときどき境の町で「〜の戦い」が起き、町の帰属が移り、人と富が減り、領主や国の長が討ち死にすることもあります。劣勢の側から、勝つ側と縁のある家（同じ氏・友好）が**寝返る**ことがあります
- **終わり方** — 一方が最後の地方を失うか戦況が振り切れれば**決着**（旧体制が勝てば**復古**、新体制が勝てば**革命の成就**）。双方が疲れ果てて膠着すれば**講和**となり、国は**二つのまま**続きます。戦は最短2年、長くても30年で終わります
- **戦後処理** — 敗れた側の中心にいた家は**改易**（所領没収・家格降下。所領をすべて失えば勝者の家の側近家に落ちる）、連なった家は**減封**、早めに寝返った家は**赦免**。没収した所領は勝者側の功のあった家へ与えられ、功のあった家は**加増・叙勲**。敗者に付いたギルド・派閥・信仰は人と力（ひいては議席）を失い、勝者に付いた側は伸び、戦で膨らんだ武のギルドは戦後に縮みます。陣営の信仰が違えば、勝者の信仰が併合した地方に広がります。占領地は荒れ、勝者の正統性は上がり、敗れた国の長は処刑され、敗れた国は滅びます
- **再戦** — 分かれたままの二国は、休戦から60年ほど経って力の差と反目が大きければ、ふたたび戦になり得ます（決着すれば**再統一**）
- 神が戦を起こすことも、勝たせることもできません。冷却期間があり、同じ国が立て続けに戦をすることはありません
- 戦は稀です。5つのシードを1500年ずつ回した実測で、放っておいた世界は1000年に平均0.5回（多い世界で1.3回、3つの世界では一度もなし）、荒れた世界で平均1.3回（多い世界で3.3回）。終わり方は復古6・講和4・革命2・再統一2

開戦と終戦は画面全体で知らせ（終戦は主な戦後処理を並べて）、戦い・寝返り・討死はニュース欄に出ます。

### 偉人

きわめて大きな功績を残した者は、後の世に**偉人**として名を残します。基準は厳しく、新しい体制を開いた・長く王だった・組織で活躍した、くらいでは載りません。多くは**死後に**、成したことが続いたと分かってから列せられます。

| 分野 | 何を成せば載るか |
|---|---|
| 統治 | **建国の父**（開いた国が120年続いた）、**中興の祖**（正統性が35%を切った国を75%まで立て直し、20年以上保った）、**名君**（30年以上の治世で民が3割以上増え、事件・政変・戦が一度もなく、正統性が6割を割らなかった） |
| 武 | **統一者**（6年以上の内戦を勝ち抜いて国を一つに戻した）、**名将**（開戦時に劣勢だった側を勝たせた）、**護国の将**（魔物が極まった時代に討伐ギルドを15年以上率い、脅威を鎮めた） |
| 信仰 | **開祖**（興した信仰が世の半ばに広がった、または興って200〜300年のうちに3地方以上に根付いていた）、**伝道の長**（教えを4地方以上広げ、世の6割に届かせた） |
| 富と技 | 世で最初の商い・職人・魔術・討伐のギルドを興し、それが**世で最も力ある組織**になった（商祖・工祖・魔導の祖・討伐の祖） |
| 変革 | 体制を倒した側を率い、その新しい秩序が**130年以上**続いた（**変革者**。奪われて興った国は、最初の長ではなくこちらで記憶される） |
| 家門 | 当主として家格を2段以上引き上げて**公爵か王家**に至らせ、50年後もその家がそこにある（**家門の祖**） |
| 思想 | 興した思想が**二つ以上の国の国是**としてのべ60年以上続いた、**150年以上国是**であり続けた、または国是となって**四つ以上の思想を生んだ**（「〜の祖」。死後に判定） |
| 要職（各分野に加わる） | **名摂政**（20年以上の摂政で国が栄え乱がない）、**名財務官**（25年以上で国の富を1.6倍）、劣勢の側を勝たせた**名将・名参謀**（武） |

実測では、放っておいた世界で1000年に平均およそ4人（静かすぎる世界では1500年に1人）、荒れた世界で5〜6人。役職に就いた者の1%に満たない数です。

偉人は系譜タブの「偉人」に分野ごとの棚で並び、まだ誰もいない分野には何を成せば載るかが薄く出ます。認定の瞬間は光と字幕で知らせ（時は止めません）、年代記と章の要約に残ります。

### 要職と家格の根拠

国には長のほかに、体制に応じた**要職**が置かれます。

| 座 | 置かれる体制・就き方 |
|---|---|
| **摂政** | 世襲の国で、長が幼い・老いた・外戚が強いとき。同じ家から三代続けば**摂関政治**（実権はその家に） |
| **財務官** | どの国にも。金権の国では最も重い座。富とギルドの後援で選ばれる |
| **元帥** | 平時の軍の長。武の家風・武勇の当主 |
| **執政補佐**（専制では**側近**） | 二席。合議・議会では議席の勢力、専制では長の寵 |
| **聖職顧問** | 神権の国で。信仰の一致 |
| **総大将・参謀** | 戦時に各陣営で。会戦と戦の結果は功・責として家に残る |
| **跡目家** | 世襲の国で、王家が絶えたとき順位どおりに継ぐ家（1〜3家）。ふつうは王家の分家（同じ氏）か外戚 |
| **氏の長者** | 各氏の筆頭の家 |

任じ方は体制で変わります（専制は長の寵と家格、合議は議席、金権は富、神権は信仰）。座ごとに**就ける家格の下限**があり、前任者の家は子が継ぎやすく、**三代続けば家職**（世襲の権利）になります。体制が変われば座は改廃されますが、「かつてその座にあった」記録は家に残ります。

実測（5世界×1000年）では、任命は1世界1000年あたり190〜310回（財務官・元帥・執政補佐が大半、摂政は世襲の国で数回）、平均在任は17〜25年、家職の成立は計125、跡目の順位の入れ替えは11。

**家格は根拠の合計**です。家を選ぶと「家格の根拠」として、現任の要職・歴任（「財務官 三代」）・家職・跡目家の順位・外戚・武功と敗戦の責・氏の長者・所領・家の古さ・叙勲（称号）・汚点が数字つきで並び、その合計が家格です。高い座が高い家格を生み、高い家格がまた高い座に就かせる——名家が名家であり続ける理由がここにあります。実測で各世界の上位5家の根拠を足し合わせると、家勢（力）13.5・歴任13.4・現任の要職11.1・家の古さ8.7・所領8.5・組織の長5.4・叙勲（称号）3.9・家職3.9・王冠3.5・氏の長者3.3、汚点−1.7。上位の家は**いま座にあり、かつて座にあった家**です。上がる道は武功・富・政変・婚姻、落ちる道は政争での失脚・断絶・敗戦・家職の喪失。

### 政争と遺恨

戦争よりずっと気軽に起きる、**武力ではなく政治力の争い**です。

- **遺恨** — 「誰が・誰を・なぜ・いつから」恨んでいるか。家督争い・継承争いに敗れた側から勝った側へ（いちばん多く、いちばん強い）、跡目の順位を越された家から越した家へ、要職を奪われた家から、戦後に所領を与えられた家へ、叙勲を剥がれた家から王家へ、破門した信仰の長へ、当主を暗殺されたと信じる家から疑われた家へ、そして政争で陥れられた家から陥れた家へ。どれも**原因の出来事**を指していて辿れます。数十年かけて薄れ（およそ60年で半分）、当主が替わるたびに少し薄れますが、世代をまたいで残ります。家の中の争いに敗れた者の恨みは、その人か子孫が家を立てた時点で家と家の恨みになります——祖父の家督争いが孫の政争になるのはこの道です
- **起こり方** — 年に一度、同じ国の宮廷にいる家同士で、遺恨が強く**機会**がある組を探します（正統性の低い体制、代替わり直後、相手が要職や高い家格を持つ、野心的な当主、同じギルド・派閥・信仰、思想の違い）。遺恨のない純粋な出世争いは稀。仕掛ける側は勝ち目を量り、見込みのない企ては滅多に起こしません。仕掛け→工作→決着と、数季〜数年かけて進みます
- **決着** — 家格と席次・現任の役職・長との近さ（関係・同じ氏・外戚）・味方の数（友好な家・同じ氏・忠実な側近家・同じ思想）・派閥の議席・信仰の一致・富・当人の気質・過去の政争の評判・守る側の利・運の11項目。体制で重みが変わり、専制では長の寵、議会では味方と議席が重い。内訳は事件タブで見られます
- **結果** — 仕掛けた側が勝てば、相手は**左遷**（要職を解かれ、資格があれば勝者がその座に就く）と**降格**（家職・跡目の順位・叙勲を失い、汚点が家格を下げ、その宮廷で一代ほど冷遇される）。大差なら当主が**隠居**に追い込まれます。露見すれば仕掛けた側が同じ罰を受け、痛み分けもあります。**どの結果でも遺恨は深まり**、次の政争のほか、家同士の関係、内戦での陣営選びと寝返り、側近家の忠誠、暗殺の条件に効きます。数代あとの**意趣返し**も起こります
- 神は直接関われません（凶作で体制の正統性が揺らげば、宮廷が騒がしくなる——それが神にできるいちばん近いこと）
- 実測（5つのシードを1000年ずつ、放っておいた世界）：政争は1000年あたり平均38件（世界ごとに29〜45件。100年に3〜4件）、同じ期間の戦は計3回。決着は仕掛けた側の勝ち80・返り討ち62・痛み分け49（ほかに立ち消え13）。**8割が家督争い・継承争いの遺恨に端を発し**、純粋な出世争いは2割弱。三代越しの意趣返しは12件、国の長や筆頭の家が失脚する大政争は4件

### 思想の系譜

政体とは別に、**考え方そのものの系譜**があります。世界の初めには一つもありません。

- **生まれ方** — ある程度自由な国（合議・議会、血統や武によらない体制、改革と通商に開かれた気風）で、豊かな町と学のある者がいるところから生まれます。不満と飢えは急進的な思想を、長い安定は守旧的な思想を、政変のあとは倒れた体制を惜しむ思想を生みやすい。もう一つは**優れた治世から**：長く安定し正統性の高かった治世や、後世が名君と呼んだ治世を、思想家が体系にします（範とした国と長を記録）。専制が続く世界ではほとんど生まれません
- **系譜** — 最初の思想が根。以降は必ず既存の思想から、**発展**（受け継いで改める）・**分派**（解釈の対立。改訂が行き過ぎても分かれる）・**反動**（ある思想への反対。反対する相手が親）・**総合**（二つを合わせる）・**復興**（60年以上前に廃れた思想を蘇らせる「新〜」）・**治世から** のどれかで生まれます。名は論点から（共和主義、正統主義、産業主義…）か、祖の名から（「〜主義」「〜学派」）。一つの世界で名は被りません
- **思想家** — 既存の人物が著作で思想を興し、弟子筋が数十年ごとに改訂します（師から弟子への筋が辿れる）。不自由な国で国是と相容れない思想家は追放・投獄され、思想は他国へ移るか地下に潜ります
- **国是** — 国は思想を国是に掲げます（新しい体制、議場を握った派閥の綱領、自ら書いた・門人である長がきっかけ）。掲げると国の向きがその教えの描く姿へ年々寄り、有力な家と派閥の共感が広ければ正統性が増し、ずれていれば減ります。綱領に掲げた派閥が体制を倒せば、新体制はその思想の姿に寄ります。採った国が栄えれば声望が上がり、倒れれば落ちて反動を生み、掲げる国も派閥もなくなれば廃れます
- **つながり** — 政争（同じ思想は味方、違う思想は対立の種）、戦争（割れた国の新しい側は旗頭の思想を掲げ、地方の領主は思想で陣営を選ぶ）、信仰（祝福または異端視）、偉人（「思想」分野：教科書に載る思想の祖のみ）、神託（「この思想が国是になる」「廃れる」）、兆し、時代（「〜主義の時代」）、史録
- 神は思想を作ることも消すこともできません（理と災厄がもたらす豊かさと不満を通じてのみ）
- 実測（同じ5世界×1000年）：最初の思想は開始から123〜333年後、1000年に生まれた思想は5〜15（平均10）、同時に生きているのは平均2〜3（最大4〜6）、改訂は平均31〜39年に一度。生まれ方は発展20・復興9・分派8・反動5・総合2・治世から1（と根5）。国是になったのは延べ14回、「思想」の偉人は5000年で6人

### 国は改まるだけでなく、倒れる

決め方が変わるだけなら、**同じ国**が新しい取り決めで続きます。国が何に拠って立つかが変わったなら（血統から構成員へ、力へ、信仰へ）、**それは別の国**であり、前の国は終わります。

倒れた国を親として継承国が建つので、系譜画面で**共和国 → 軍事政権 → 王国**と遡れます。追われた統治者は、その国の後継すべてに「前体制の長」として記憶されます。

### 統治のかたちと政変

「派閥」と「政体」が何を表すのかは、**両者の力関係から決まる政体の形**として表に出ます。神殿派閥が最も強ければ神権国家に、商業ギルドが強く議会があれば商人共和国に、家々が領を分け持てば封建王国に。

そして**国の仕組みそのものが奪われます**。議席の過半を握った派閥、王冠より重くなったギルド、抑えの利かなくなった民衆——誰かが国を支えている状態が続くと政体の正統性は削れていき、限界を越えると**政変**が起きます。何を正統性の根拠とするか（世襲／選挙／実力／神権／軍事／金権）と、誰が決めるか（専制／評議制／議会制）が書き換えられ、血筋に依らない体制になれば王は座を追われます。

### 危機が生む新しい politics

不満が限界を越えれば**平等派**が、災厄が続けば**終末教団**が、魔物の脅威が存亡に関わるところまで来れば**軍政派**が、富が王の徴税を越えれば**自由都市派**が、資材と魔術が伝統を追い越せば**秘儀技術派**が生まれます。これらは親派閥の思想を少しずらしたものではなく、**正統性の根拠と意思決定の形ごと否定した別物**です。同じ類型の組織は3つまでしか並び立たないので、似た派閥ばかりが並ぶことはありません。

### 身分 ── 貴族と側近家

各貴族家には**側近家**が3つ付いています。平民ではなく、貴族でもない。領地を持たず、貴族との婚姻は容易ではない。だからこそ**行き先がある**のがこの身分の要点で、道は3つあります。

| 道 | 条件 |
|---|---|
| **反乱** | 忠誠を失い、なお主家に匹敵する力を持ったとき、実力で領を奪う |
| **血統的乗っ取り** | 主家の生きている血の過半が側近家由来になり、誰も忠義を惜しまなくなったとき、争いなく家督が移る |
| **恩賞** | 政体を奪った貴族が、敵対する貴族から領を没収して降格させ、自分の腹心を貴族に列する |

逆向きも起きます。降格した貴族家は消えるのではなく、**自分を負かした家の側近家に落ちる**。その孫の代がまだ払っている借りです。

身分を越えた婚姻は「重み付け」ではなく**拒否**されます。ただし、同格の家すべてと不仲になった家には他に相手がおらず、そのときだけ線が越えられる。越えた縁組は多くの場合**駆け落ち**として扱われ、当人たちは家から除かれて一段下の家として再出発します。

### 宗教

世界は**アニミズム**から始まります。司祭も教義も指導者もなく、山と川と死者に祈るだけ。これが信仰系統の根であり、後のすべての宗教はここまで遡れます。

組織された宗教は、世界が求めたときに分派します。凶作が続けば豊穣信仰、魔物が夜ごと出れば守護神信仰、家々の重みが増せば祖霊信仰、資材と魔術が溢れれば秘儀信仰、災厄が重なれば終末信仰。生まれた信仰は最初の一地域を得て、そこから広がります。地域が改宗し、その地の家が信仰を改め、家が自分の他の所領にそれを持ち込む——という循環です。

### 家風

家には**貴族一家・神官一家・騎士一家・学究一家・商家・郷士の家**という性格があります。建国時は土地の産業から決まり、以後は**その家が実際に何をしてきたか**で読み直されます。代々神殿に子を出していれば、何から始まったかに関わらず神官一家です。

家風は効きます。**学究一家**が長を出している組織は分派しやすく、**貴族一家**は封建王国の形そのものを支えていて、諸家が貴族一家でない王国は同じ王冠でも脆い。

### 継承と家督争い

**継承は基本的に揉めません。** 世襲の座は長子が継ぎ（男子優先）、誰も何も言いません。争いが起きるのは理由があるときだけ——跡取りが明らかに兄弟姉妹より劣る、野心的な者が隙を見る、家長が幼い直子を残して没して家督が横に流れる。座を選挙や実力で埋める組織（ギルドや派閥）は、そもそも「争い」ではなく**選出**として記録されます。

争いになった場合は、**穏やか／中程度／激しい**の三段階で決着します。段階は、票差の僅少さ・敗者の野心・座の重み・**幼君**（家長が幼い直子を残して没し、家督が横に流れる）から決まります。

| 段階 | 決着 |
|---|---|
| 穏やか | 敗者は争わずに**隠居**する。その座には二度と担がれないが、他の役職には就ける |
| 中程度 | 敗者は家を出て**分家**を立てる（世界に家を増やす余地がない場合は隠居に落ちる。起きなかった出奔を年代記に書かないため） |
| 激しい | 敗者は**廃嫡**され、家を追われる。以後どこの座にも就けない |

中程度以上では**側近家が旗色を選びます**。誰を推したかは年代記に名指しで残り、勝者を推した家は格が上がり、敗者を推した家は下げられます。

### 分家の理由

家が割れるには他にも理由があり、年代記にその理由が残ります。**跡目不当**（家長の器量が足りず、明らかに優れた兄弟姉妹が仕えることを拒む）、**駆け落ち**（家格を越えた縁組を家が認めない）。

### 家同士の関係

家と家の関係は、実際に起きたことから毎回読み直されます。婚姻で結ばれていれば近づき、同じギルドの座を争っていれば離れ、理念が隔たれば冷えていく。王冠を戴く家は、戴かない家から妬まれます。関係は蓄積された感情ではなく現状の反映なので、原因が消えれば対立も終わります。

## 設計

詳細は [`docs/DESIGN.md`](docs/DESIGN.md)。要点だけ:

- **系譜の追跡可能性** — 組織の設立・分派・継承はすべて `HistoryLog.record()` を通り、そこから `GameState.apply()` が状態を書き換える。他の経路から書き換えることはできないので、年代記と系譜が食い違うことがない。系譜に不可欠な出来事は圧縮されない永続領域に残る。
- **権力の算出はデータ駆動** — 「魔物が多いと討伐ギルドが強くなる」は特別扱いではなく、`data/power_profiles/*.tres` が宣言した世界変数の重み付けの一例。新しい組織の類型を足すのに、エンジン側のコード変更は要らない。
- **政治体制は生成される** — 固定パターンから選ぶのではなく、権力基盤×意思決定構造の離散2軸と、世界の状況に応じて漂流する連続5軸から組み立て、そこから体制名と説明文を生成する。ギルドや派閥の思想も同じ仕組み。
- **神の権限の境界** — `GodPowerAPI` には組織も人物も権力値も渡せない。この境界はテストで機械的に検証している。

## 開発

Godot **4.7** 以上（`Dictionary[K,V]` の型付き構文を使うため 4.4 が下限）。

```bash
# エディタで開く
godot --path .

# ヘッドレスのテスト（23本・1プロセスで回すと数時間。--spec=名前 で個別に実行でき、
# spec ごとに別プロセスで並列に回すのが速い。
# test_touch はスマホと同じ順でタッチを送り、スワイプ・タップ・ダイヤルを確かめる。
# test_reachable は全画面で「見えているボタンに指が届くか」を確かめる）
godot --headless --path . res://tests/TestRunner.tscn

# 数百年ぶんを一気に回して結果を眺める開発用ツール
godot --headless --path . res://tools/Diagnose.tscn -- --ticks=2400 --seed=7

# 複数のシードを長く回し、戦・偉人・事件・要職・政争・思想の回数と1ティックの時間を数える
godot --headless --path . res://tools/Census.tscn -- --seeds=1,2,3 --years=1500 --mode=quiet

# 各画面のスクリーンショット（要 xvfb）。--phone でスマホの縦長画面と上下の帯を再現、
# --cache で早送り済みの世界を使い回す
xvfb-run -a --server-args="-screen 0 720x1600x24" \
  godot --path . --resolution 720x1600 res://tools/Screenshot.tscn -- --phone --out=/tmp/shots
```

テストには系譜の不変条件が含まれます（氏は `test_uji`、戦は `test_war`、偉人は `test_greatness`、要職と家格は `test_offices`、政争と遺恨は `test_intrigue`、思想は `test_ideology`）。2万ティック回した世界に対して、すべての組織が種別ごとにただ1つの根へ到達すること、思想もただ1つの根へ到達すること、循環がないこと、すべての人物の家系が始祖で終わること、セーブが完全に往復すること、同じシードが同じ歴史を生むことを検証しています。

## Android APK のビルド

必要なもの:

- Godot 4.7 本体と、**同じバージョンの** Android エクスポートテンプレート（エディタの *Editor → Manage Export Templates* から導入）
- JDK 17 以上
- Android SDK の build-tools（`apksigner`, `zipalign`, `aapt2`）と platform-tools（`adb`）
- Godot のエディタ設定で `export/android/android_sdk_path` と `java_sdk_path` を上記に向ける

```bash
# デバッグ版（Godot が自動生成するデバッグ鍵で署名される）
godot --headless --path . --export-debug "Android" build/keizai-debug.apk

# リリース版 — 鍵はリポジトリに置かず環境変数で渡す
export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/secure/path/keizai-release.keystore
export GODOT_ANDROID_KEYSTORE_RELEASE_USER=keizai
export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=...
godot --headless --path . --export-release "Android" build/keizai-release.apk
```

リリース鍵は `keytool -genkeypair -v -keystore keizai-release.keystore -alias keizai -keyalg RSA -keysize 2048 -validity 10000` で作成し、**リポジトリの外に置いて必ずバックアップ**してください。これを失うと同じ Play Store の掲載を更新できなくなります。

ビルド結果の実測値:

- 最小 SDK 24（Android 7.0）／ターゲット SDK 36（Android 16）
- arm64-v8a のみ（32bit を含めると 59MB になるため既定では外しています。必要なら `export_presets.cfg` の `architectures/armeabi-v7a` を `true` に）
- 権限要求は**ゼロ**（通信・位置情報・カメラのいずれも使いません）
- 画面の端まで描き（`screen/edge_to_edge` = on）、時計やナビゲーションの帯は**ゲームの上に重ねて**表示します。操作する部分はゲーム側で帯の内側に収めます（`ui/main/safe_area.gd`）。設定から帯を隠す全画面にも、上下の余白を手で広げることもできます
- デバッグ 32MB／リリース 30MB

**ターゲット SDK は提出時に Google Play の当時の要件を確認してください。** この要件は毎年上がります。

### 未検証の項目

このリポジトリの APK はコンテナ内でビルド・署名検証まで確認済みですが、**実機での起動確認は行っていません**（実行環境に Android 端末もエミュレータもないため）。実機で確かめるべきは、タップ操作の感触、ピンチ操作、長時間放置後の復帰、セーブの読み込み時間、旧セーブ（氏のない版、要職・遺恨・思想のない版）を読み込んだときの見え方、「偉人」「思想」画面のスクロール、関係図の遺恨の破線の見やすさです。
